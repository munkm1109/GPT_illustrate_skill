# Reference Analysis Checklist

Summary: Use this checklist to turn a reference set into a coherent style pack rather than a pile of disconnected observations.

## Analyze the set in this order

1. What emotion does the set repeatedly aim for?
2. How does the set handle composition and focal placement?
3. What value and lighting patterns recur?
4. How are faces and eyes handled?
5. What line and shape language dominates?
6. How is color restricted or released?
7. How is texture and density controlled?
8. What motifs repeat often enough to count as style?
9. What should never appear if this wrapper is being respected?
10. What generic model-default habits would weaken this reference set?

## Evidence rule

When extracting style rules:

- one-off detail = weak evidence
- repeated trait across multiple references = strong evidence

## Separation rule

Always separate:

- direct observation
- inferred preference

## Output rule

The final style pack should read like:

- a reusable drawing behavior system

not like:

- a review essay
- a fan description
- an image caption list
