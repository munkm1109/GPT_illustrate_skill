# Distribution Manifest

Built: 2026-05-08 Asia/Seoul

## Included

- Base workflow: `illustrate-skill/`
- Reference analysis/style builder: `reference-copy-skill/`
- Object/anatomy/scene companion: `object-research-skill/`
- Validator/pipeline assets: `templates/`, `scripts/`
- Local object cards and scene recipes: `illustration-library/`
- Docs: `docs/`

## Explicitly Excluded

- `derived-style-skills/` and all generated style wrappers
- `Reference-*` raw image folders
- `.omx/` private run state and generated specs
- `output/`, previous `dist/` bundles, generated images, caches
- `Char_pack/`, `spec-builders/`, and one-off local run artifacts

## Current Mechanism Notes

- Render-bound SPEC runs require staged artifacts.
- Theory-read proof is required.
- Strict object-research validation is supported.
- Camera-distance style-lock theory is part of the base illustration workflow.
- Pixel-plane reference analysis is part of `reference-copy-skill` and is the official first-pass method for reference-folder style analysis.
- Style wrappers can be generated by users later, but they are not bundled in this distribution.
