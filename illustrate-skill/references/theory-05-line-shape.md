# THEORY_05_LINE_SHAPE

Summary: This theory locks the style by assigning different line character to different parts of the scene and by decomposing large forms into a controlled shape language. It sits on top of silhouette and value rather than replacing them.

Summary: Step 5 must decide where thin sensitive lines belong, where thick broken lines belong, what shape families to use, and how those shapes guide the viewer from the eyes through the rest of the image.

## Purpose

2단계에서 만든 큰 실루엣과 3단계 명암 위에, 부위별로 다른 선의 성격과 셰이프 리듬을 부여해 스타일을 고정한다.
머리카락·손·턱선은 얇고 예민한 선, 옷·배경은 굵고 끊긴 선, 그리고 삼각형/파편/꽃잎/리본 형태의 면 분해를 일관되게 적용하기 위한 이론이다.

이 단계에서 먼저 결정해야 하는 것:

- 어디에 얇은 선 / 굵은 선을 쓸지
- 어떤 부분을 삼각형, 파편, 리본, 꽃잎 형태로 쪼갤지
- 어떤 셰이프로 시선 흐름을 유도할지

## Basic concepts

### Line quality

선은 두께, 압력, 속도, 연속성에 따라 감정과 질감을 전달한다.

- thin sensitive line -> delicacy, tension, sharpness
- thick rough line -> weight, noise, rough material, structure
- broken line -> incompleteness, abrasion, fragmented atmosphere

### Shape language

기본 셰이프가 주는 인상:

- triangle -> danger, sharpness, aggression, motion
- square / rectangle -> stability, mass, structure
- curve / round shape -> softness, organic flow

이 스타일의 핵심은 삼각형, 파편, 리본, 뾰족한 꽃잎형의 적극적 사용이다.

## Part-based line rules

### Thin sensitive group

대상:

- hair
- fingers and hands
- jawline
- nose indication
- eye area

역할:

- 인물의 생명력
- 예민함
- 시선 집중 포인트

규칙:

- 가장 얇은 선 그룹으로 유지
- 빠른 선감은 허용하되 불필요한 떨림은 줄인다
- 보조선 남발보다 핵심 선만 남긴다

### Thick broken group

대상:

- large clothing folds
- accessories
- background structures
- architectural outlines
- shard / ribbon outer edges

역할:

- 화면 리듬
- 질감
- 구조
- 배경 노이즈 대비

규칙:

- 얇은 그룹보다 1-2단계 굵게
- 일부러 끊거나 거칠게 처리해 먹 번짐, 스크래치, 파편감을 만든다

### Line weight count

기본 규칙:

- use 2 line-weight levels as default: thin / thick
- allow a third heavier accent only if clearly needed
- do not exceed 3 levels

## Shape decomposition rules

### Large form to smaller shape breakdown

분해 대상:

- clothing planes
- background dark masses
- light masses
- shards
- petals
- ribbons

셰이프 유형:

- triangle pieces
- glass-shard polygons
- long curved ribbons
- pointed petal-like forms

규칙:

- triangle / shard shapes increase danger and tension
- ribbon shapes guide the eye
- petal-like shapes introduce elegance without softening the image too much

### Gaze-guiding shapes

2단계에서 정한 시선 흐름을 5단계의 shape direction으로 강화한다.

규칙:

- align shard, ribbon, and petal directions from eyes -> face zone -> key supporting object
- avoid sending major shape vectors straight out of frame
- if a form exits outward, curve or redirect it back into the picture

## Line vs shape role split

선과 면은 다르게 다뤄야 한다.

- line -> outline, boundary, scratch rhythm, structural emphasis
- shape -> value block, color block, directional movement, mood

규칙:

- decide where no line is needed and a shape-only read is stronger
- in this style:
  - face and hands -> line and shape both remain fine and sensitive
  - clothing and background -> shape first, line second, with broken/noisy treatment

## Step 5 execution summary

1. Re-read Step 2 silhouette and Step 3 value plan.
2. Split the image into line groups:
   - thin sensitive group
   - thick broken group
3. Map line-weight assignments and keep them within 2-3 levels.
4. Break large clothing and background planes into:
   - triangles
   - shards
   - ribbons
   - pointed petal forms
5. Align those shapes with the intended gaze flow.
6. Decide where shape alone should carry the read and where line must reinforce the edge.
7. Check the image at reduced size and judge whether the style reads through line and shape alone.

## Gate

Do not continue to Step 6 unless all are true:

- sensitive parts use thin line logic while clothing/background use thicker broken logic
- line-weight stages remain controlled within 2-3 levels
- large planes are broken into a coherent shard / ribbon / petal language
- shape direction guides the eye from eyes -> face -> key support object
- line and shape alone already suggest the intended dangerous / tense / gothic / neon mood

If any item fails, revise line hierarchy or shape decomposition before color.
