# Theory 02C - Anatomy Structure Gate

Purpose: Before detailed rendering, lock a believable human figure structure using an age-band body base, a sex overlay, a temporary default body-type baseline, and a hand submodule.

## Core rule

Do not solve hands in isolation.

For scenes with meaningful human figure read:

1. choose an **age band**
2. choose a **sex classification overlay**
3. choose the current **body-type baseline**
4. bind the **hand module** to that body decision
5. only then solve grips, finger grouping, and prop contact

## Required age-band taxonomy

Use one of these values exactly:

- 초등학생
- 중학생
- 고등학생
- 20대초반
- 20대후반
- 30대초반
- 30대후반
- 40대초반
- 40대후반
- 50대초반
- 50대후반

## Sex classification rule

Use a sex-classification note whenever the body read matters.
It can stay broad, but it must be explicit enough to affect:

- shoulder vs hip read
- ribcage vs pelvis emphasis
- limb thickness bias
- neck / jaw / torso rhythm
- hand size and wrist read

The goal is not rigid biology or stereotype policing.
The goal is draw-stable structure and silhouette intent.

## Temporary body-type rule

Detailed body-type taxonomy is intentionally deferred.
For now, use one broad baseline:

- a beautified default body read aligned to the user's current intent
- e.g. the kind of aesthetically pleasing baseline implied by keywords such as `미녀`, `미소녀`, `미남`

Do not invent many body subtypes yet.
Lock one usable baseline and move on.

## What must be written in the gate

- age band
- sex classification
- body-type baseline
- body anatomy base card
- sex overlay card
- hand anatomy submodule card
- stylization level
- head-to-body ratio
- ribcage-pelvis relation
- shoulder width note
- hip width note
- limb proportion note
- elbow-wrist chain note
- hip-knee-ankle chain note
- hand-size relative note
- foot-size relative note

## Hand-submodule rule

Hands are downstream of the body decision.

That means:

- hand size must agree with age band
- wrist thickness must agree with the forearm chain
- gesture force must agree with shoulder / elbow setup
- grip logic must agree with the body posture and prop scale

If the hand looks correct only when isolated but breaks the figure, the hand solution is wrong.

## Gate triggers

Run the anatomy gate when any of the following are true:

- full-body, half-body, thigh-up, seated, leaning, jumping, lunging, twisting
- visible shoulders / torso / pelvis / legs / arms matter to the read
- visible hands are focal, expressive, foreshortened, or gripping
- the source image already contains broken anatomy that needs repair
- the prompt implies age-coded or sex-coded body language

## Output standard

The written anatomy notes must be concrete enough that another artist could rebuild:

- the body mass hierarchy
- the shoulder / pelvis relation
- the arm and leg chains
- the hand scale and role

If that cannot be reconstructed from the notes, the gate is not complete.
