# Line / Plane / Intent Analysis

This document is the deep analysis layer behind the reference-derived wrapper.
Use it when the user wants finer “선 / 면 / 의도 / 왜 이게 안티-제너릭인지” control rather than only the stage-biased style pack.

## 1. Line Breakdown

### A. 얼굴선

- 눈 윗선은 가장 강한 얼굴선이다.
- 아래 눈꺼풀은 완전한 닫힌 선보다 부분선, 그림자선, 색면으로 대체되는 경우가 많다.
- 코는 선으로 다 설명하지 않는다. 콧대 전체를 두껍게 둘러싸기보다 코끝과 옆면 전환만 암시한다.
- 입은 길고 얇은 선 또는 매우 작은 명암차로 처리한다.
- 표정 연기는 선의 양보다 눈매 각도와 입꼬리 미세 이동으로 만든다.
- “예쁜 표정”보다 “온도가 읽히는 시선”이 우선이다.

### B. 머리선

- 머리카락은 `덩어리 -> 리본 -> 칼끝` 순으로 분해된다.
- 앞머리는 얼굴을 가리는 차폐선이자 시선 유도선 역할을 한다.
- 긴 머리는 중력선만 따르지 않고 화면 구도를 따라 휘어진다.
- 끝선은 둥글게 감기기보다 날카롭게 빠지거나 꺾인다.
- 단순히 매끈하게 정리하면 긴장감이 빠진다.

### C. 손선

- 손가락은 길고 얇게 설계된다.
- 손끝, 손톱, 마디는 예민한 리듬으로 마감된다.
- 손은 감정 과장이 아니라 `기품 / 유혹 / 통제 / 거리감`을 보조하는 제스처 도구다.
- 손 실루엣이 둔해지면 전체 스타일의 세련감이 바로 무너진다.

### D. 의상선

- 외곽선보다 절개선, 리본 끝, 레이스 끝, 장식 분기선이 중요하다.
- 천 주름은 둥근 원통주름보다 쐐기형 / 꽃잎형 / 갈라진 면 전환으로 보이는 경우가 많다.
- 검은 장식은 선으로만 설명하지 않고 검은 면 자체가 외곽 역할을 겸한다.
- 무늬와 장식은 단순 장식이 아니라 시선 흐름 장치다.

### E. 구조선

- 창틀, 기둥, 파라솔 살, 유리판, 케이지, 와이어, 표지판, 무기 프레임은 화면의 압력축을 담당한다.
- 구조선은 인물선보다 거칠거나 단단해도 된다.
- 배경선은 `정리된 설계선 + 감정적 잡음선`이 함께 존재한다.
- 여기서 너무 깨끗해지면 장면의 위협과 밀도가 약해진다.

## 2. Plane Breakdown

### A. 피부면

- 큰 덩어리로 조용하게 남긴다.
- 면 분할 수를 줄여 얼굴과 피부가 읽히는 속도를 빠르게 만든다.
- 붉은기 / 살색 / 보랏기 반투명층으로 부드럽게 변주한다.
- 피부 자체가 너무 정보량이 많아지면 환경 압력과의 대비가 사라진다.

### B. 머리면

- 큰 리본면이 먼저이고, 반사 띠가 그 위에 지나간다.
- 하이라이트는 덩어리 흐름을 끊지 않고 따라가되, 몇 군데는 칼날처럼 날카롭게 끊긴다.
- 머리면은 단순 광택보다 방향성과 분할감이 중요하다.

### C. 의상면

- `검은 큰 면 + 장식용 작은 면 + 광택 하이라이트 면`으로 구성된다.
- 레이스와 프릴은 실루엣을 흐리는 솜털이 아니라 방향성을 가진 톱니 / 꽃잎 / 쐐기 면이다.
- 의상면은 몸을 감싸는 동시에 배경과 경쟁할 수 있는 두 번째 구조 장치다.

### D. 결정 / 무기 / 유리면

- 한 번에 읽히는 큰 축면이 있고, 그 위에 작은 파편면이 겹친다.
- 흰색 면은 단순 조명이 아니라 화면을 자르는 절단면처럼 쓰인다.
- 너무 유기적으로 풀어버리면 references 특유의 절삭감이 약해진다.

### E. 배경면

- 배경은 `통짜 암부 / 광면`으로 시작한 뒤, 중간에 기호적 세부를 삽입한다.
- 식물, 건축, 표지판, 패턴, 장미, 파편, 반사수면, 수조, 프레임은 배경을 비우지 않기 위한 밀도 장치다.
- 배경은 풍경이 아니라 감정 기계처럼 작동해야 한다.

## 3. Intent Inference

### 기본 의도 모델

이 reference-derived 계열 이미지는 대체로 다음 문장 구조로 압축된다.

> “아름답고 통제된 인물이, 감정이 걸린 구조물 / 장치 / 의식의 중심에 서 있다.”

### 자주 반복되는 의도 축

- 아름다움 + 위험
- 정지 + 내적 압력
- 성스러움 + 인공성
- 우아함 + 파손감
- 차가움 + 미세한 생기

### Scene archetypes

1. **의식의 왕좌**
   - 왕좌, 왕관, 날개, 월식, 대칭
   - 의도: 접근하기 어려운 권위

2. **파손된 결정장**
   - 검정 공간, 유리 파편, 흰 절단광
   - 의도: 아름다운 붕괴

3. **인공 정원 / 온실 / 수조**
   - 식물 + 수조 + 네온 + 경고표지 + 프레임
   - 의도: 살아 있는 것과 설계된 것이 충돌하는 낙원

4. **고딕 실내극**
   - 창, 장미, 체커 바닥, 의자, 붉은 포인트
   - 의도: 연극처럼 연출된 기억과 감정

5. **선 중심 스케치 초상**
   - 단색, 얇은 선, 절제된 표정
   - 의도: 색 없이도 긴장과 기품이 유지되는가의 검증

## 4. Anti-generic interpretation

### Why generic model output fails here

- 배경을 흐림 처리만 하면 “압력 시스템”이 사라진다.
- 선을 균일하게 정리하면 부위별 위계가 사라진다.
- 얼굴을 너무 귀엽게 만들면 장면의 심리 온도가 무너진다.
- 광택과 bloom을 과하게 뿌리면 초점이 아니라 소음이 된다.
- 의상면을 둥글고 부드럽게만 처리하면 구조적 긴장이 사라진다.

### What to force instead

- 배경은 반드시 이야기 / 구조 / 상징 / 위협 중 하나를 담당하게 한다.
- 얼굴은 감정 과장 대신 시선과 미세 근육의 차이로 읽히게 한다.
- 큰 면부터 잘라 넣고, 작은 디테일은 그 후에 붙인다.
- accent는 “많이”가 아니라 “정확히” 꽂는다.

## 5. How to Apply in Practice

### 얼굴을 그릴 때

- 먼저 감정보다 시선의 방향과 눈매 온도를 결정한다.
- 입은 최소 정보로 두고, 눈의 광택 구조로 감정을 밀어 올린다.
- lashes / iris / upper lid가 얼굴선의 핵심이다.

### 의상을 그릴 때

- 봉제선보다 큰 검은 면과 방향성 있는 절개면을 먼저 설계한다.
- 프릴 / 리본 / 장식은 후순위 장식이 아니라 시선 흐름 장치로 본다.
- 하이라이트는 면의 방향을 설명해야지 표면을 미끄럽게만 만들면 안 된다.

### 배경을 그릴 때

- 배경이 비면 이 계열의 장면은 거의 무너진다.
- 단, 정보량은 많아도 초점과 같은 대비 / 채도를 갖게 해서는 안 된다.
- 구조물은 얼굴을 밀어주는 압력 프레임이어야 한다.

### 색을 넣을 때

- 한 장면의 세계관 색을 먼저 잠그고, 눈 / 결정 / 꽃 / 표지판 / 프레임에만 강한 포인트를 준다.
- 포인트를 여러 군데 나누기보다 `주 초점 1, 보조 초점 1-2`로 제한한다.

## 6. Failure Modes

- 선을 모두 균일하게 정리해서 맛이 사라짐
- 피부와 옷의 질감 차이가 없음
- 배경을 흐림 처리만 해서 서사 장치가 사라짐
- 눈보다 리본 / 배경 광원이 먼저 보임
- 색이 많아져서 초점이 퍼짐
- 표정 연기를 크게 해서 절제가 깨짐
- 환경은 복잡한데 얼굴이 여전히 중심이 되지 못함
- “예쁘게 정리된 이미지”는 되었지만 압력과 이야기 장치가 사라짐
